📍 MASALAH SEKARANG:
───────────────────────────────────────────────────────────────
   Data siswa yang sudah diimport tidak muncul karena:
   ❌ "Missing or insufficient permissions"


✅ SOLUSI:
───────────────────────────────────────────────────────────────
   Publish Firestore Rules di Firebase Console!


⚡ LANGKAH CEPAT (5 MENIT):
───────────────────────────────────────────────────────────────

1️⃣  BUKA: https://console.firebase.google.com/

2️⃣  PILIH PROJECT: "absensi-jamaah"

3️⃣  KLIK: Firestore Database (sidebar kiri)

4️⃣  KLIK: Tab "Rules" (di atas)

5️⃣  DELETE semua kode yang ada

6️⃣  PASTE kode rules ini:

    ┌─────────────────────────────────────────────────┐
    │ rules_version = '2';                            │
    │ service cloud.firestore {                       │
    │   match /databases/{database}/documents {       │
    │     match /admins/{adminId} {                   │
    │       allow read, write: if request.auth != null;│
    │     }                                            │
    │     match /students/{studentId} {               │
    │       allow read, write: if request.auth != null;│
    │     }                                            │
    │     match /attendance/{attendanceId} {          │
    │       allow read, write: if request.auth != null;│
    │     }                                            │
    │     match /settings/{settingId} {               │
    │       allow read, write: if request.auth != null;│
    │     }                                            │
    │   }                                              │
    │ }                                                │
    └─────────────────────────────────────────────────┘

7️⃣  KLIK: Tombol "Publish" (biru, kanan atas)

8️⃣  TUNGGU: 30 detik

9️⃣  REFRESH website (F5)

🔟 CEK: Menu "Data Siswa" → Data harus muncul! ✅
