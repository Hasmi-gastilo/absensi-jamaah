═══════════════════════════════════════════════════════════════
   🔥 CARA PUBLISH FIRESTORE RULES - LANGKAH CEPAT
═══════════════════════════════════════════════════════════════

🚨 ERROR SEKARANG:
   "Missing or insufficient permissions"

✅ SOLUSI:
   Publish Firestore Rules di Firebase Console

───────────────────────────────────────────────────────────────
📍 LANGKAH 1: BUKA FIREBASE CONSOLE
───────────────────────────────────────────────────────────────

1. Buka browser Chrome/Edge/Firefox
2. Ketik URL: https://console.firebase.google.com/
3. Login dengan akun Google
4. Klik project: "absensi-jamaah"

───────────────────────────────────────────────────────────────
📍 LANGKAH 2: MASUK KE FIRESTORE
───────────────────────────────────────────────────────────────

1. Di sidebar KIRI, cari menu "Firestore Database"
2. Klik "Firestore Database"
3. Anda akan lihat data (admins, students, dll)

───────────────────────────────────────────────────────────────
📍 LANGKAH 3: BUKA TAB RULES
───────────────────────────────────────────────────────────────

1. Di ATAS (sebelah tab "Data"), ada tab "Rules"
2. Klik tab "Rules"
3. Anda akan lihat editor kode

───────────────────────────────────────────────────────────────
📍 LANGKAH 4: GANTI RULES
───────────────────────────────────────────────────────────────

1. SELECT ALL (Ctrl+A) di editor rules
2. DELETE semua kode yang ada
3. COPY kode rules di bawah ini:

┌────────────────────────────────────────────────────────────┐
│ rules_version = '2';                                       │
│ service cloud.firestore {                                  │
│   match /databases/{database}/documents {                  │
│     match /admins/{adminId} {                              │
│       allow read, write: if request.auth != null;          │
│     }                                                       │
│     match /students/{studentId} {                          │
│       allow read, write: if request.auth != null;          │
│     }                                                       │
│     match /attendance/{attendanceId} {                     │
│       allow read, write: if request.auth != null;          │
│     }                                                       │
│     match /settings/{settingId} {                          │
│       allow read, write: if request.auth != null;          │
│     }                                                       │
│   }                                                         │
│ }                                                           │
└────────────────────────────────────────────────────────────┘

4. PASTE (Ctrl+V) ke editor rules

───────────────────────────────────────────────────────────────
📍 LANGKAH 5: PUBLISH
───────────────────────────────────────────────────────────────

1. Cari tombol "Publish" (berwarna BIRU, di kanan atas)
2. Klik tombol "Publish"
3. Tunggu 10-30 detik

───────────────────────────────────────────────────────────────
📍 LANGKAH 6: TEST WEBSITE
───────────────────────────────────────────────────────────────

1. Kembali ke website (localhost:5500)
2. REFRESH halaman (tekan F5)
3. Klik menu "Data Siswa"
4. Data siswa SEHARUSNYA MUNCUL SEKARANG! ✅

───────────────────────────────────────────────────────────────
🎯 HASIL YANG DIHARAPKAN
───────────────────────────────────────────────────────────────

✅ Data siswa yang diimport dari Excel muncul di tabel
✅ Tidak ada error "permission" di Console (F12)
✅ Bisa tambah/edit/hapus siswa
✅ Semua menu berfungsi normal

───────────────────────────────────────────────────────────────
⏰ CATATAN PENTING
───────────────────────────────────────────────────────────────

⚠️ Setelah klik "Publish", tunggu 10-30 detik
⚠️ Kadang perlu sampai 1-2 menit untuk propagasi
⚠️ Jika masih error, tunggu 2 menit lalu refresh lagi
⚠️ Jika masih gagal, clear cache browser (Ctrl+Shift+Delete)

───────────────────────────────────────────────────────────────
🔍 CEK BERHASIL ATAU TIDAK
───────────────────────────────────────────────────────────────

1. Buka Console browser (tekan F12)
2. Pergi ke tab "Console"
3. Refresh halaman students.html

BERHASIL jika:
✅ Tidak ada error merah "permission"
✅ Data siswa muncul di tabel
✅ Tabel tidak kosong/loading terus

GAGAL jika:
❌ Masih ada error "Missing or insufficient permissions"
❌ Tabel kosong atau "Gagal memuat data siswa"

Jika gagal → tunggu 2 menit lagi → refresh lagi

═══════════════════════════════════════════════════════════════

📋 RINGKASAN SINGKAT:

1. https://console.firebase.google.com/
2. Pilih project "absensi-jamaah"
3. Firestore Database → Tab "Rules"
4. Delete semua → Paste rules baru
5. Klik "Publish"
6. Tunggu 30 detik
7. Refresh website
