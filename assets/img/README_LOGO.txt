INSTRUKSI: CARA MENAMBAHKAN LOGO SMK N 1 SANGASANGA
=====================================================

1. Simpan logo sekolah dengan nama: logo-smk.png
2. Letakkan di folder ini: assets/img/logo-smk.png
3. Format yang disarankan:
   - PNG dengan background transparan (recommended)
   - Ukuran: 500x500px atau lebih tinggi
   - Ratio: 1:1 (kotak/square)

4. Setelah menyimpan logo, refresh halaman login dan dashboard
5. Logo akan muncul dengan efek animasi yang elegan:
   - Floating effect (naik turun)
   - Rotating background
   - Pulsing glow
   - Zoom in/out subtle

CATATAN:
- Jika logo belum ada, aplikasi akan error saat load gambar
- Pastikan nama file EXACT: logo-smk.png (huruf kecil semua)
- Jangan gunakan spasi atau karakter khusus dalam nama file
